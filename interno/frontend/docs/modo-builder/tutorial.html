1. ¿Qué es el Constructor de Modos?

Es un editor visual tipo Scratch. Arrastras bloques desde la paleta al lienzo para definir la lógica de tu modo. Cada bloque es una acción: mostrar texto, cambiar colores, reproducir sonidos, gestionar preguntas, controlar concursantes, etc.

El constructor compila tus bloques a un formato AOT (Ahead-Of-Time) que el backend ejecuta de forma segura y determinista durante el show en vivo.

2. La Interfaz

  • Paleta (izquierda): catálogo de bloques por categoría. Arrástralos o haz clic para añadirlos.
  • Lienzo (centro): aquí construyes tus pilas de bloques. Cada evento tiene su propia pestaña.
  • Inspector (derecha): muestra detalles del bloque seleccionado.
  • Consola (abajo): muestra el stepper en vivo durante la ejecución.
  • Vista previa: pulsa Vista para ver en tiempo real cómo quedará en pantalla.
  • Dark mode: pulsa 🌓 para alternar entre modo claro y oscuro.

3. Bloques de Eventos (Hat) — Amarillo

Todo modo empieza con un bloque Hat (sombrero) que indica el evento que dispara la cadena.

Al precargar preguntaon_question_loadCuando se carga una pregunta en memoria (antes de mostrarla).
Cuando cronómetro iniciaon_question_startCuando el cronómetro empieza a correr en vivo.
Al pulsar concursanteon_player_buzzCuando un jugador pulsa su buzzer.
Al confirmar respuestaon_player_answerCuando un jugador envía su respuesta.
Al llegar a ceroon_timer_expireCuando el cronómetro llega a cero.
Si nodo pierde redon_hardware_disconnectCuando un nodo local se desconecta.
Al recibir señalon_custom_signalCuando se recibe una señal personalizada.
Consejo: usa on_mode_init para configurar el tema, inicializar variables y establecer el estado inicial. Usa on_question_start para el flujo principal del quiz.

13. Arrastrar y Soltar

  • Arrastra un bloque de la paleta al lienzo para crear una pila nueva.
  • Arrastra un bloque del lienzo sobre otro para insertarlo encima (mitad superior) o debajo (mitad inferior).
  • Puedes tener varias pilas sueltas: suéltalas en un área vacía del lienzo.
  • Selecciona un bloque y pulsa Supr para borrarlo.

14. Vista Previa en Tiempo Real

Pulsa Vista para abrir un panel que simula cómo se verá tu modo en pantalla.

  • Temas: el preview aplica los colores del tema seleccionado (neon, retro, oscuro, custom).
  • Texto: los bloques set_text_smooth muestran su contenido.
  • Imágenes/Video: se muestran como placeholders con el nombre del archivo.
  • Efectos: partículas, animaciones, filtros se listan como indicadores visuales.
  • Gradientes: se renderizan como fondo de la pantalla de preview.

15. Exportar / Importar

Guarda y carga tus creaciones:

  • 💾 Exportar — descarga un archivo .json con tu modo.
  • 📂 Importar — carga un archivo .json previamente exportado.
  • ⬇ Guardar — guarda el borrador en el navegador (localStorage).
  • ⬆ Cargar — restaura el último borrador guardado.
  • Auto-save: el builder guarda automáticamente en cada cambio. Al recargar la página, se restaura.
Formato JSON del export:
{
  "version": 1,
  "type": "scratch-mode",
  "heads": {
    "on_mode_init": [
      { "opcode": "set_theme", "args": {"THEME": "neon"}, "next": { ... } }
    ]
  }
}

19. Power Pack — Bloques de Potencia ⚡

El Power Pack añade capacidades de potencia extrema al constructor: matemáticas avanzadas, manipulación real de strings, iteración sobre listas, bucles con rango, control de salida, ranking y persistencia en vivo. Todos estos bloques están incluidos en la whitelist del backend (_security.py) y se ejecutan de forma determinista en el runtime AOT.

20. Ejemplos Paso a Paso

Ejemplo 1: Pantalla de bienvenida

  1. En la pestaña on_mode_init, arrastra set_theme y selecciona "neon".
  2. Añade set_text_smooth con COMP: "titulo" y TXT: "¡Bienvenidos!".
  3. Añade play_sfx con FILE: "welcome.mp3".
  4. Pulsa Vista para ver el resultado.

Ejemplo 2: Quiz con tema custom

  1. En on_mode_init: set_custom_theme con BG: "#1a0533", TXT: "#e0c3fc", ACC: "#ff6b6b", FNT: "Poppins".
  2. Añade set_gradient_bg con DIR: "↘", C1: "#1a0533", C2: "#0c0c1d".
  3. Añade quiz_init_engine con N: 20, CAT: "mixed".
  4. En on_question_start: quiz_fetch_next_question → set_text_smooth → wait_seconds → quiz_lock_answers.
  5. En on_player_answer: quiz_verify_player_answer → quiz_add_score_to_player.

Ejemplo 3: Mostrar imagen de fondo

  1. En on_mode_init: set_background_image con SRC: "background.jpg".
  2. Añade set_text_smooth con el texto superpuesto.
  3. Añade set_text_shadow para que el texto sea legible sobre la imagen.
Consejo: empieza siempre por el bloque on_mode_init y construye de arriba hacia abajo. Usa la Vista previa a menudo para verificar el resultado.
Importante: los bloques de tipo contenedor (si/entonces, repetir, intentar/si falla) aún no soportan cuerpos anidados en el editor visual. Están planeados para una futura versión.
